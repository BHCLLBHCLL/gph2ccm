## D4 高阶单元调研（结论永久成立）

- 结论：**legacy CCM 无高阶（二次）单元语义**，#21 保持 ❌ 是正确且永久的
  （非「未适配」而是「格式链两端均无高阶」）。证据链：
  1. 上游 GPH 线性：gphdecoding 全库 grep 无 quadratic/curved/mid-side；
     `LS_Nodes` 只有顶点坐标，`LS_Links` npe=3..11 是任意多边形/多面体面。
  2. libccmio `CCMIOWriteFaces` 面流可装任意 nVerts，但只是多边形面，无
     「边中点/曲线几何」语义。
  3. legacy CCM 单元形状 = `CellTopologyType`（PROSTAR 形状码），只有线性
     形状（tet/hex/wedge/pyramid/polygon/polyhedron=255），无二次形状码。
     gph2ccm 统一写 255=polyhedral。
  4. STAR-CCM+ `STAR_QUADRATIC_*`（21–26/29）是**有限元求解器**单元类型，
     与 legacy CCM FV 导入无关；UserGuide 明说 mesher 不生成 mid-side node，
     全文 0 处「curved mesh/cell」。
- 写入：评估矩阵 #21 行 + 评估文档 D4 → ✅ + `version_behavior_table.md` #15。
- 未来若上游出现真高阶数据源（如 CGNS 高阶元素），须走 STAR-CCM+ 原生格式
  而非 legacy CCM，超出本工具范围。
