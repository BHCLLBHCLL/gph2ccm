## gph2ccm 转换代码问题分析

通读 `gph2ccm/` 全包（convert/model/ccmio/verify/reorder/deps/__main__），产出问题分析报告
`conversion_issues_analysis.md`（项目根目录）。核心发现：

- **H1** `--split-fluid-regions --verify` 必然误报：interface 两侧 volume patch 共享真实 face id，
  而 verify.py:134 断言跨 region face id 唯一。
- **H2** grid-interface 虚拟 face id（`fids+1+n_faces` / `+2*n_faces`）使 map max_id 声明近 3 倍面数，
  语义未对照 STAR-CCM+ 原生导出验证。
- **M1** `chunk_vertices` 参数完全失效：`_write_vertices` 单次写入，`--chunk-vertices` CLI 误导。
- **M2** 顶点 float32 转换对大尺度网格有精度损失（convert.py:389）。
- **M3** `_short_label` 截 16 字符可能致 interface label 碰撞。
- **M4** `write()` 无 try/finally，异常时文件句柄泄漏。
- 低优先：face_cells 先于 faces 写入、cvol 覆盖无告警、质心用面心均值、processor 逻辑冗余。

已正确处理：顶点/face_cells 单次写入规避 dll 2D 分块 bug、边界 region 去重、face_stream 1-D 分块、RCM 重排。
